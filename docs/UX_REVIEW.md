# MealKit Manager UX/UI 검토와 개선안

작성: 2026-11-13. 대상: Manager 0.2.x (`4c6dd6b` 왼쪽 내비게이션, 두 줄 프로젝트 행).
기준: 처음 의도한 모습은 **Godot 프로젝트 매니저처럼, 프로젝트 목록 하나가 전부인 런처**였다. 지금 Manager는 기능을 하나씩 덧붙이다가 "관리 도구"가 되었다. 이 문서는 런처로 되돌리는 방향을 정한다.

## 1. 지금 무엇이 이상한가

화면 확인: `build\bin\MealKitManager.exe --frames 30 --capture` (사용자 폴더 실제 목록).

| # | 문제 | 지금 모습 | 왜 문제인가 |
|---|---|---|---|
| P1 | 페이지가 너무 많다 | 왼쪽 내비게이션에 프로젝트 / 모듈 / 엔진 / 도구 4개, 190px를 늘 차지 | 사람은 Manager를 "프로젝트 열기"로 연다. 나머지 3개는 가끔 쓰는데 첫 화면 폭의 1/6을 쓴다 |
| P2 | 모듈 페이지가 Manager에 있다 | 프로젝트 콤보로 고른 프로젝트의 모듈 추가/업데이트/삭제 | 모듈은 프로젝트 안의 일. 에디터의 [모듈] 창이 같은 일을 같은 `module.ps1`로 한다. 두 곳에서 같은 일을 하면 "어디서 해야 하지?"가 생기고, 에디터가 열린 프로젝트를 밖에서 바꾸는 위험도 있다 |
| P3 | 열기 버튼이 따로 있다 | 선택/호버한 행에 파란 [열기] 알약 버튼 | 더블클릭과 Enter가 이미 연다. 버튼이 행마다 나타났다 사라져서 목록이 흔들리고, 화면의 유일한 accent가 매번 다른 행으로 옮겨 다닌다 |
| P4 | 즐겨찾기 별이 숨어 있다 | 즐겨찾기가 아니면 호버할 때만 보임 | 있는 줄 모른다. Godot처럼 행 맨 앞에 늘 보여야 누를 생각을 한다 |
| P5 | 아이콘이 의미 없는 글자 타일 | 이름 첫 글자 + 해시 색. `icon` 줄이 없으면 늘 이 모습 | 템플릿에 `icon` 줄도 `icon.png`도 없어서 사실상 모든 프로젝트가 글자 타일. 바꾸는 방법도 화면에 없다 (mealkit.project를 손으로 고쳐야 함) |
| P6 | 이름과 경로를 바꿀 수 없다 | 경로는 툴팁과 [더보기]에만, 이름은 고칠 곳이 없음 | 런처에서 가장 흔한 정리 작업(이름 바꾸기, 폴더 옮기기)이 불가능. 엔진에는 이미 `tools\rename_project.ps1`이 있다 |
| P7 | 경로가 행에 없다 | 둘째 줄이 "엔진 0.9.4 · 날짜" | 같은 이름 프로젝트(복사본, 테스트용)를 구분할 수 없다. 엔진 버전은 거의 모든 행이 같아서 정보가 아니다 (TOOL_DESIGN 3.2 "같은 값을 모든 행에 반복하지 않는다"를 스스로 어김) |
| P8 | 언어 설정이 없다 | 에디터 설정의 `language`를 읽기만 함. 바꾸려면 `--lang` 또는 에디터에서 | Manager는 처음 실행하는 프로그램이다. 에디터를 열기 전에 언어를 바꿀 방법이 없다 |
| P9 | 하단 상태 바 | 평소에는 "MealKit Manager 0.2.x" 한 줄, 작업 중에는 진행 표시, 실패 시 출력 버튼, 업데이트 알림 | 버전 한 줄을 위해 한 줄 높이를 늘 쓴다. 작업/오류/업데이트는 자주 일어나지 않으니 필요할 때만 나타나면 된다 |
| P10 | 행이 너무 크고 비어 있다 | 행 높이 60px, 오른쪽 대부분이 빈 공간 | 6~7개만 보인다. 정보는 두 줄인데 공간은 세 줄 |
| P11 | 툴바가 두 줄 | 제목 줄([가져오기...][새 프로젝트]) + 검색 줄([없는 프로젝트 빼기 (7)][정렬]) | "없는 프로젝트 빼기"는 가끔 쓰는 정리 기능인데 상시 버튼. 검색과 정렬은 한 줄이면 된다 |
| P12 | 시작할 때 백그라운드 작업이 보인다 | "빌드 도구 확인... (0s)"가 상태 바에 뜸 | 사용자가 시킨 일이 아닌데 "작업 중"처럼 보인다. 결과가 문제일 때만 보이면 된다 |

## 2. 방향

1. **첫 화면 = 프로젝트 목록.** 내비게이션을 없애고 목록이 창을 다 쓴다.
2. **프로젝트 안의 일은 에디터에서.** 모듈은 Manager에서 뺀다.
3. **행에서 바로 고친다.** 별, 아이콘, 이름, 경로는 행에서 눌러서 바꾼다 (Godot보다 한 단계 더 직접적: Godot은 [편집] 대화상자를 거친다).
4. **열기는 더블클릭 / Enter 하나.** 행에 [열기] 버튼을 두지 않는다.
5. **상시 막대는 없다.** 상태는 일이 있을 때만 나타난다.

### 3.1 머리줄

- 왼쪽: 앱 로고 + "MealKit". 버전은 여기 툴팁 (사용자 폴더 경로도 같이).
- 가운데: **[프로젝트 | 도구]** 두 칸 전환 (Godot의 Projects / Asset Library, Creative Cloud의 Apps 탭과 같은 자리). 도구에 업데이트가 있으면 점(●). Ctrl+1 / Ctrl+2. 왼쪽 내비게이션 대신 이 두 칸이 전부다.
- 검색 + 정렬 한 줄. 정렬: 최근 / 이름 / 만든 날짜 (엔진 정렬은 뺀다: 대부분 같은 값).
- 오른쪽: [가져오기] (보조 버튼), [+ 새 프로젝트] (화면의 유일한 primary 버튼, TOOL_DESIGN 1 "한 화면에 main action 하나"). 열기가 버튼이 아니게 되면서 primary가 새 프로젝트로 돌아온다.
- [⚙] 설정 (3.4). 엔진과 도구도 여기서 들어간다.

### 3.2 프로젝트 행

높이 96px, 아이콘 64px, 이름은 큰 본문 글꼴 (2026-11-13 사용자 요청으로 52px에서 두 배 가까이 키움). 왼쪽부터:

| 요소 | 동작 | 구현 메모 |
|---|---|---|
| **★ 즐겨찾기** | 늘 보임 (꺼짐 = 회색 외곽선 별, 켜짐 = 주황 채운 별). 클릭으로 전환 | 지금 코드의 별을 맨 앞으로, 호버 조건 제거 |
| **아이콘** (40px) | 기본은 **MealKit 로고**. 클릭 → PNG 파일 고르기 → 프로젝트 폴더에 `icon.png`로 복사하고 `mealkit.project`의 `icon` 줄 기록. 우클릭 메뉴에 [기본 아이콘으로] | 로고는 `MealKit/engine/res/MealKitEditor.png`를 Manager `res/`에 복사해 임베드 (엔진 링크 금지 규칙). 글자 타일 코드는 삭제. 호버 시 아이콘 위에 연필 오버레이로 "누를 수 있음"을 보인다 |
| **이름** | 클릭 → 그 자리에서 입력칸. Enter 확정, Esc 취소, F2도 같은 동작. 규칙(영문자 시작, 영문/숫자/_)을 입력 중에 빨간 테두리 + 툴팁으로 알림 | 엔진 `tools\rename_project.ps1 -Project -Name` 호출 (이미 있음, build\ 삭제 포함). 확정 전 작은 확인: "exe 이름도 바뀌고 build 폴더를 지워요" |
| **경로** (둘째 줄, 회색) | 클릭 → 폴더 고르기. 폴더가 **있으면** 그 위치로 프로젝트를 **옮긴다** (확인 대화상자: "D:\A\X를 D:\B\X로 옮겨요"). 폴더가 **없으면** "찾기": 옮겨진 폴더를 가리키게 목록만 고친다 | 옮기기: 같은 드라이브는 rename, 다른 드라이브는 복사 후 삭제. `build\`는 CMake 캐시에 절대 경로가 있어서 지운다. 에디터가 그 프로젝트를 열고 있으면 거절. 엔진 쪽에 `move_project.ps1`이 필요한지 먼저 결정 (4절 Q2) |
| **엔진 버전** | 작은 회색 태그 (Godot의 `4.3` 태그처럼). 설치된 엔진과 다르면 주황 | |
| **상태 / 고치기** | 문제가 있을 때만: [엔진 0.9 설치], [업그레이드 a → b], 폴더 없음 → [찾기...], mealkit.project 없음 → 빨간 글자 | 지금 로직 그대로 |
| **⋯ 더보기** | 탐색기에서 보기, 경로 복사, 이름 바꾸기, 아이콘 바꾸기, 폴더 옮기기, 목록에서 빼기 | 우클릭 메뉴와 같은 내용. [모듈 관리] 항목 삭제 |

- **열기**: 더블클릭, Enter. 툴팁 없이도 Godot/탐색기와 같아서 알 수 있다. 처음 실행 때만 빈 상태 아래 한 줄로 "더블클릭해서 열어요".
- **선택**: 한 번 클릭 = 선택 (회색 5 배경만. 왼쪽 accent 막대는 2026-11-13에 뺐다). 이름/경로/아이콘은 **이미 선택된 행**에서 눌렀을 때만 편집으로 들어간다 (탐색기의 "선택 후 한 번 더 클릭"과 같은 규칙). 그래야 목록을 훑으며 클릭할 때 실수로 편집되지 않는다.
- **없는 프로젝트**: [없는 프로젝트 빼기 (N)] 상시 버튼을 없애고, 없는 프로젝트가 있을 때만 목록 맨 위에 한 줄 안내 "폴더를 찾을 수 없는 프로젝트 7개 · [목록에서 빼기]".

### 3.3 하단: 일이 있을 때만

- 평소: 아무것도 없다. 목록이 창 끝까지.
- 사용자가 시킨 작업(새 프로젝트, 업그레이드, 설치, 이름 바꾸기, 옮기기) 중: 하단에 한 줄 띠가 올라온다 (진행 원호 + 이름 + 초). 끝나면 성공은 3초 뒤 사라지고, 실패는 [출력] 버튼과 닫기 [×]가 있는 채로 남는다.
- 시작할 때의 빌드 도구 확인, 릴리스 목록 읽기는 **조용히**. 결과가 문제일 때만 목록 위 안내(지금의 컴파일러 없음 배너)로 보인다.
- Manager 업데이트: 머리줄 로고 옆 작은 점 + 설정의 [업데이트 후 다시 시작]. 상태 바를 차지하지 않는다.

### 3.4 설정 (⚙)

모달 하나, 왼쪽에 작은 목록 (일반 / 엔진). 가끔 쓰는 것을 모두 모은다. 도구는 설정이 아니라 자기 탭에 둔다 (3.6).

- **일반**: 언어 (한국어 / English, 즉시 적용), 새 프로젝트 기본 위치, Manager 버전과 [업데이트 확인], 사용자 폴더 열기.
  - 언어는 에디터와 같은 설정이어야 한다 (지금 Manager가 에디터 설정의 `language`를 읽음). 쓰기는 mkcontract에 `setEditorSetting`이 없어서 **MealKit-Contract에 먼저 추가**하고 vendor로 가져온다 (Manager CLAUDE.md 규칙).
- **엔진**: 지금 엔진 페이지 내용 (설치된 엔진, 사용 프로젝트 수, 에디터 빌드, 릴리스에서 설치, 엔진 폴더 추가).
  엔진은 사용자가 직접 고를 일이 드물다: 새 프로젝트는 설치된 최신 엔진, 다른 PC에서 온 프로젝트는 행의 [엔진 0.9 설치]가 알아서 맞춘다. 그래서 탭이 아니라 설정에 둔다.

### 3.5 새 프로젝트 대화상자

지금 구조 유지, 다듬을 것만:

- 제목 줄과 [만들기]를 primary로 (지금은 일반 버튼).
- 엔진이 하나뿐이면 엔진 콤보 숨김. 경로 미리보기는 회색 한 줄 그대로.
- 아이콘 고르기는 넣지 않는다: 만든 뒤 행에서 바꾸면 된다.

### 3.6 도구 탭: MkAudio, MkUI, MkRender, (나중에) QA

배경: 엔진 DECISIONS 2026-11-12 "사용자는 Manager만 받고, Manager가 엔진과 도구를 설치/업데이트한다". 지금은 이걸 [도구] 페이지의 표 두 개(설치됨 / 설치)로 하는데, 받을 수 있는 도구가 "설치" 표 아래쪽에 있고, 호환 안 되는 이유는 회색 글자, 열기는 표의 작은 아이콘이라 **"MealKit에 오디오 도구가 있다"는 걸 알 수가 없다.** 미들웨어는 MealKit을 고르는 이유 중 하나이므로 Creative Cloud의 앱 목록처럼 보여야 한다.

```
┌─ 도구 ─────────────────────────────────────────────────────────────────┐
│ [♪ 아이콘] MkAudio      0.3.1                              [열기 ▾]   │
│            게임 사운드 이벤트와 믹스를 만들어요                         │
│ [▦ 아이콘] MkUI         0.1.4 → 0.1.5                [업데이트]  ⋯    │
│            게임 화면(UI)을 디자인해요                                   │
│ [◆ 아이콘] MkRender     —                            [설치 · 42 MB]   │
│            머티리얼과 셰이더를 미리 봐요                                │
│ [✓ 아이콘] MkQA         —                                 준비 중      │
└────────────────────────────────────────────────────────────────────────┘
```

**구현 (2026-11-13)**: 위 그림의 행 대신 **카드 그리드**(기본 창 크기에서 2열, 넓으면 3열). 카드: 실제 앱 아이콘(각 도구 저장소 `tool/res/<Tool>.ico`의 128px를 `src/ToolIcons.h`에 임베드), 이름, 상태 줄(초록 점 + 버전 설치됨 / a -> b / 설치 안 됨과 이유), 한 줄 설명, 아래쪽에 여는 파일 형식 태그와 상태 버튼. **suite 도구 4개(MkAudio, MkUI, MkRender, MkQA)는 설치·릴리스 목록과 상관없이 늘 보인다** (설명은 Manager의 표, `kSuiteTools`). 그 밖의 도구는 뒤에 이름순, 아이콘은 manifest `icon` 키워드의 글리프.

**설치**
- 릴리스 인덱스의 도구를 **설치 여부와 상관없이 늘 같은 자리**에 보인다. 행: 앱 아이콘(TOOL_DESIGN 5의 suite 아이콘), 이름, 한 줄 설명, 오른쪽에 상태 하나: [설치 · 크기] / [업데이트] / [열기].
  - 설명과 아이콘은 인덱스에 필요하다: 엔진 `release_index.ps1`의 tools 항목에 `summary`, 아이콘 키워드를 추가 (엔진 쪽 먼저).
- **버전 맞추기는 Manager가 한다.** 사용자는 버전을 고르지 않는다. 설치된 엔진 MINOR와 맞는 최신 버전을 설치하고, 맞는 게 없으면 버튼 대신 "엔진 0.10 필요" + [엔진 설치]. protocol이 다르면 "Manager 업데이트 필요" + [업데이트]. 지금처럼 회색 글자로 막다른 길을 만들지 않는다.
- **엔진을 처음 설치할 때 함께 고른다** (Unity Hub의 "모듈 추가"처럼): 엔진 설치 대화상자에 맞는 도구 체크박스, 기본 모두 체크, 각 크기와 합계. 처음 실행한 사람이 한 번에 다 갖춘다.
- **업데이트**: 탭의 점(●) + 탭 위 한 줄 "업데이트 2개 · [모두 업데이트]". 도구나 에디터가 실행 중이면 지금처럼 거절하되, 행에 "MkUI를 닫으면 업데이트돼요"라고 말하고 닫히면 자동으로 진행.
- **삭제**: ⋯ 메뉴 [제거] (확인 대화상자, 프로젝트 파일은 그대로임을 말한다). 지금은 삭제 방법이 없다.
- 설치/업데이트 진행은 행 안의 진행 막대 (하단 띠도 같이). 여러 개를 동시에 누르면 순서대로.

**열기**
- 도구는 늘 프로젝트를 들고 열린다 (`<exe> --project <folder>`, CONTRACT "Tool manifest"). 그래서 열기는 세 군데:
  1. **프로젝트 행 ⋯ / 우클릭 → [도구로 열기 ▸ MkAudio, MkUI, …]**. 설치 안 된 도구는 [MkRender 설치 후 열기]로 같은 자리에 보인다.
  2. **도구 탭의 [열기 ▾]**: 누르면 마지막에 선택한 프로젝트로 열고, ▾는 최근 프로젝트 목록 (분할 버튼). 프로젝트가 없으면 "프로젝트 없이 열기"만.
  3. **에디터의 [도구] 메뉴** (이미 있음, `module-Editor` `Tools.cpp`): 에디터에서 일하는 중이면 대부분 여기서 연다. 여기에 **설치 안 된 도구도 회색 항목 "Manager에서 설치..."**로 보이게 하고, 누르면 `MealKitManager --install-tool <name>`을 실행한다 (Manager에 이미 있는 명령). 이 목록은 Manager가 인덱스를 읽어 사용자 폴더에 남긴 캐시에서 온다 → mkcontract에 "받을 수 있는 도구" 파일 형식 추가가 필요.
- 미들웨어의 **런타임**(게임에 들어가는 mkaudio, mkui 라이브러리)은 Manager가 설치하지 않는다. 엔진과 함께 오거나 프로젝트의 모듈(에디터 [모듈] 창)로 들어간다. Manager가 다루는 건 **만드는 앱**뿐이다. 도구 행 툴팁에 "게임에 넣는 건 에디터의 모듈에서" 한 줄.

## 4. 없애는 것

| 없앰 | 대신 |
|---|---|
| 왼쪽 내비게이션, Ctrl+1..4 | [프로젝트 \| 도구] 두 칸 + ⚙ 설정 |
| 도구 페이지의 "설치됨 / 설치" 두 표 | 도구 탭의 한 목록 (설치 여부와 상관없이 같은 행) |
| 모듈 페이지 (`modulesTab`, `runModuleTool`, `ModuleList` 파싱, `--tab modules`, `RowAction::Modules`) | 에디터의 [모듈] 창. Manager에서는 아무 진입점도 두지 않는다 |
| 행의 [열기] 버튼 | 더블클릭 / Enter |
| 상시 상태 바와 버전 표시 | 작업 중에만 나타나는 띠, 버전은 로고 툴팁과 설정 |
| 글자 타일 아이콘 | MealKit 로고 |
| [없는 프로젝트 빼기] 상시 버튼 | 없을 때만 나오는 안내 줄 |
| 엔진 정렬 | (빼도 됨) |

## 5. 결정이 필요한 것

- **Q1. 언어 설정 위치.** Manager와 에디터가 같은 `language`를 쓰는 안(추천: 한 번 바꾸면 둘 다 바뀜) vs Manager 전용 설정.
- **Q2. 폴더 옮기기를 누가 하나.** 지금은 에디터 안의 프로젝트 매니저(`editor/ProjectManager.cpp`, DECISIONS 2026-10-16)가 C++로 옮긴다. 엔진에 `tools\move_project.ps1`로 꺼내고 Manager는 호출만 (추천: CLAUDE.md "엔진 스크립트에 없는 기능은 엔진 쪽에 먼저"). DECISIONS 2026-10-27/11-12에 따라 Manager가 이름·옮기기·아이콘을 갖추면 `ProjectManager.cpp`는 지운다.
- **Q5. 도구 설명/아이콘과 "받을 수 있는 도구" 캐시.** 릴리스 인덱스 tools 항목에 `summary`·아이콘 추가(엔진 `release_index.ps1`), 에디터 [도구] 메뉴용 캐시 파일 형식(mkcontract). 둘 다 다른 저장소 변경이라 순서가 필요하다.
- **Q3. 이름 = exe 이름.** 지금 엔진은 표시 이름과 exe 이름이 같다. 한글/공백 이름을 원하면 `mealkit.project`에 `title` 줄을 따로 두는 엔진 변경이 필요. 이번에는 지금 규칙 유지(추천).
- **Q4. 모듈 페이지 삭제에 맞춰 엔진 `docs/TOOL_DESIGN.md` 수정.** 4절 "Pages … (the Manager's Modules) has its own picker", 3.2 "the row's main action (`Open`) shows on the hovered or selected row", 1절의 예 `Open in Editor`가 Manager 기준이라 함께 고쳐야 한다. 새 규칙: "런처 목록은 행 버튼 없이 더블클릭/Enter로 연다", "상태 바는 상시가 아니다(occasional screen)".

## 6. 작업 순서 (커밋 단위)

진행 (2026-11-13): 1~10 모두 반영. 확인은 빌드, 테스트, `--capture` 화면(가짜 릴리스 목록 포함)까지이고, 파일·폴더 선택 창을 거치는 흐름(아이콘, 이름, 옮기기, 찾기), 실제 다운로드 설치, 에디터 [도구] 메뉴는 손으로 확인하지 않았다.
남은 것: 도구가 닫히면 자동으로 업데이트(3.6, 지금은 거절 메시지), 각 도구 저장소 `mealkit-tool.txt`의 `summary`/`icon` 줄. 에디터 안 프로젝트 매니저는 엔진 5b02a41(module editor v0.2.4)에서 지웠다.

1. **화면 줄이기**: 내비게이션을 [프로젝트 | 도구] 두 칸으로, 모듈 페이지와 관련 코드/문자열/테스트 삭제, 엔진 페이지를 설정 모달로 이동, 상태 바를 작업 중 띠로. TOOL_DESIGN 수정 (Q4).
2. **행 다시 그리기**: 별 앞으로·상시 표시, 경로 둘째 줄, 엔진 태그, 행 높이 48px, [열기] 버튼 제거, primary를 [새 프로젝트]로, 없는 프로젝트 안내 줄.
3. **아이콘**: MealKit 로고 임베드, 클릭으로 PNG 고르기 → `icon.png` 복사 + `icon` 줄 기록 (Catalog에 쓰기 함수 + 테스트), 기본으로 되돌리기.
4. **이름 바꾸기**: 그 자리 입력, 검증, `rename_project.ps1` 호출, 에디터가 열고 있으면 거절.
5. **경로 바꾸기**: 찾기(없는 폴더 다시 가리키기)와 옮기기. Q2 결정에 따라 엔진 스크립트 먼저.
6. **언어 설정**: MealKit-Contract `setEditorSetting` 추가 → vendor → 설정 일반 탭.
7. **도구 탭**: 한 목록, 상태 버튼 하나, 자동 버전 맞추기, [열기 ▾], 제거, 모두 업데이트. 프로젝트 행 [도구로 열기 ▸].
8. **엔진 설치 때 도구 함께 고르기**.
9. **다른 저장소 (Q5)**: 엔진 `release_index.ps1`에 도구 설명/아이콘 → Manager가 표시. mkcontract 캐시 형식 → 에디터 [도구] 메뉴에 "Manager에서 설치...".
10. Manager 업데이트 알림을 로고 점으로.
